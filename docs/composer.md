# سازندهٔ بصری (بدون کد)

هدف این بخش ساده است: ساخت پست ریچ بدون دانستن هیچ تگی.

## چطور کار می‌کند
1. مینی‌اپ را از ربات باز کن و تب **ساخت بصری** را انتخاب کن.
2. یک **قالب** بزن (پست کانفیگ، اطلاعیه، آموزش، فروش، معرفی اکانت) یا از صفر شروع کن.
3. از نوار بلوک‌ها هر چیزی که لازم داری اضافه کن؛ هر بلوک را باز کن و فقط فیلدهایش را پر کن.
4. سمت راست، پیش‌نمایش زنده همان لحظه ساخته می‌شود.
5. **استفاده و ارسال پست** را بزن: متن به ادیتور منتقل می‌شود و از همان‌جا در کانال منتشرش می‌کنی.

## بلوک‌ها
| بلوک | چه می‌سازد |
|---|---|
| تیتر | سرخط با سه اندازه |
| متن | پاراگراف با استایل ساده/بولد/ایتالیک/هایلایت |
| نقل‌قول | باکس متنی، با زیرنویس و حالت بازشونده |
| جمله برجسته | یک جملهٔ شاخص بیرون از باکس |
| فهرست | بولت، شماره‌دار یا تیک‌باکس |
| جدول | ردیف/ستون داینامیک، راه‌راه، حاشیه‌دار |
| دکمه‌ها | دکمه رنگی: باز کردن لینک یا کپی متن |
| عکس | تصویر با کپشن اختیاری |
| بخش بازشو | جزئیات تاشو |
| متن مخفی | اسپویلر |
| ساعت زنده | زمان محلی هر کاربر |
| فرمول | LaTeX |
| جداکننده | خط فاصله |

## نکته‌های کاربردی
- متن‌ها ساده‌اند ولی سه نشانهٔ سریع کار می‌کنند: `**بولد**`، `*ایتالیک*` و `==هایلایت==`.
- دکمه‌های کپی‌متن برای کانفیگ و اکانت بهترین انتخاب‌اند: کاربر با یک لمس کپی می‌کند.
- ترتیب بلوک‌ها با فلش‌های بالا/پایین هر بلوک عوض می‌شود؛ کپی و حذف هم همان‌جاست.
- بوم خودکار در مرورگر ذخیره می‌شود؛ بستن مینی‌اپ کارت را از بین نمی‌برد.
