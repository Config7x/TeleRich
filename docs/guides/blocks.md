# بلوک‌ها · Blocks

۸۶ بلوک در ۹ دسته. هر بلوک در استودیو یک فرم کوچک است و در فایل `miniapp/src/library.ts` تعریف شده: `fields` (فرم) و `render` (HTML).

## ساختار یک بلوک

```ts
add({
  key: 'config',
  title: 'کانفیگ کپی‌شو',
  cats: ['فنی'],
  icon: '⌨️',
  hint: 'کانفیگ داخل بلاک‌کوت تودرتو',
  fields: [
    { k: 'name', label: 'نام', type: 'text' },
    { k: 'config', label: 'کانفیگ', type: 'area' },
  ],
  def: { name: '🇩🇪@Config7x', config: 'vless://…' },
  render: (v) => `…`,
});
```

## دسته‌ها

رایج (۱۲) · متن (۱۲) · رسانه (۱۰) · داده (۱۲) · فروش (۱۱) · تعامل (۷) · کانال (۶) · فنی (۷) · پیشرفته (۵)

## افزودن بلوک تازه

۱. یک `add({...})` در `library.ts` بنویس
۲. `npm test` — تست همهٔ بلوک‌ها را می‌سنجد: خروجی غیرخالی و تگ‌های متوازن
۳. `npm run build && npx wrangler deploy`

هیچ جای دیگری لازم نیست عوض شود؛ فرم و پیش‌نمایش خودکار ساخته می‌شوند.
