# مدیا · Media

| نوع | روش |
|---|---|
| عکس | بلوک «تصویر» یا ارسال با `sendPhoto` |
| آلبوم | چند عکس با یک کپشن؛ کپشن و دکمه‌ها به همان گروه پاسخ داده می‌شوند |
| ویدیو | `sendVideo` با کپشن ریچ |
| فایل | `.ovpn` و `.conf` مستقیم و بدون خواندن محتوا ارسال می‌شوند |
| گیف و ویس | به‌عنوان انیمیشن و پیام صوتی |

## نکتهٔ تصویر در متن

تصویر باید در بلوک خودش باشد؛ تگ `<img>` تنها در ابتدای پیام یا بعد از یک تیتر معنی دارد. اگر آدرس تصویر نامعتبر باشد، پیش‌نمایش جای خالی نشان می‌دهد و ارسال انجام نمی‌شود.
