# جدول، نمودار و آمار · Tables, charts, stats

## جدول

```html
<table bordered striped compact>
  <tr><th>سرور</th><th>پینگ</th></tr>
  <tr><td>🇩🇪 آلمان</td><td>42ms</td></tr>
</table>
```

پرچم‌ها: `bordered` (خط دور)، `striped` (ردیف یک‌درمیان)، `compact` (فشرده).

## کارت آمار

بلوک «کارت آمار» سه عدد را کنار هم می‌گذارد: کاربر، پینگ، آپ‌تایم. برای عددهای بزرگ از `mark` استفاده کنید تا چشم اول آن را ببیند.

## نمودار

نمودار میله‌ای و خطی با نویسه‌های بلوکی (`█ ▁▂▃`) ساخته می‌شوند؛ چون تصویر نیستند، در همهٔ کلاینت‌ها و در حالت ذخیرهٔ داده هم دیده می‌شوند.
